
A clean and modern company website built using **HTML5** and **CSS3**, featuring a hero banner, service highlights, company profile, clients section, and a structured footer.  
This project is fully responsive and suitable for corporate or trading companies.

## 🚀 Features

- Modern corporate UI design  
- Responsive layout (desktop + mobile)  
- Hero banner with call-to-action  
- About Us section  
- Services grid (Food Trading, Building Materials, Import/Export, Contracting)  
- Client showcase section  
- Email subscription box  
- Footer with quick links and social icons  
- Clean HTML + CSS structure



## 🧩 Tech Stack

| Technology | Purpose |

| **HTML5** | Structure of the website |
| **CSS3** | Styling and layout |
